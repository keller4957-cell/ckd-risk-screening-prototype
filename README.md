# 신장 이상 위험 선별 시제품

NHANES 2021–2023 공개자료로 학습한 연구용 기준모델을 연결한 로컬 Streamlit 프로그램임.

## 실행 방법

VS Code에서 이 프로젝트 폴더를 연 뒤, 아래 명령을 터미널에 입력함.

```powershell
& "C:\Anaconda\python.exe" -m streamlit run app.py
```

실행 후 브라우저가 열리면 다음 기능을 사용할 수 있음.

- **개별 선별:** 한 사람의 선별 위험확률, 입력값별 모델 반영 방향, eGFR·UACR 단일검사 시점 해석을 확인함.
- **참고집단 비교 그래프:** 입력 연령·성별과 같은 NHANES 참고집단의 평균 및 25~75백분위 범위에 현재 입력값을 겹쳐 표시함.
- **다인 일괄분석:** 프로그램에서 내려받은 Excel 양식 또는 CSV 파일을 올려 여러 명을 동시에 분석함.

참고집단은 eGFR 60 이상 및 UACR 30 mg/g 미만인 NHANES 성인의 집계 통계임. 앱에는 개인 단위 NHANES 원자료를 넣지 않음.

## 주의사항

- 이 프로그램은 확진·진단·치료결정 도구가 아님.
- 한 번의 검사 시점에서 eGFR < 60 또는 UACR >= 30 mg/g 가능성을 선별하는 연구용 기준모델임.
- 실제 임상 사용 전 한국 자료 외부검증, 재보정, 재학습 및 의료진 검토가 필요함.
- 입력값을 저장하지 않도록 만들었지만, 실제 환자 식별정보는 입력하거나 CSV에 넣지 않는 것을 권장함.
